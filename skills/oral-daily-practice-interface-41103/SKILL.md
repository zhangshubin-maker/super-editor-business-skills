# 口语天天练界面型教辅（41103）

按 `0.1.7` 试制规则执行。完整读取 [rule-pack.json](references/rule-pack.json)、
[workflow.md](references/workflow.md) 和 [batch-and-provenance.md](references/batch-and-provenance.md)。

## 核心边界

- 完整原课件和样章 41103 是正式依据；`41103_analyse.json` 只用于核对历史槽位，不决定语义。
- 目标书使用手机端画布，宽度 375；保留样章布局和样式，不复制原课件视觉样式。
- 目录主标题复制源目录完整名称，只折叠首尾与连续空白，不改大小写、标点或 Day 序号。
- 目录主标题默认保持 18px；先扩展至“查看”入口前的安全宽度。中等长标题保持单行并降至 16px；仍放不下的超长标题保持 16px、改为两行和 48px 高度，同时把 Dialogue 区整体下移 24px、顶部区块增高 24px。标题必须完整且不得遮挡“查看＋箭头”或下方内容。
- 句型按“Sentence Pattern / 句型”语义段提取，保持来源实际存在的二至三句、原顺序和标点；不得为空位编造第三句。
- 句型正文默认 16px；若最长句在 280px 文本框中仍会右侧裁切，统一降至能完整显示的最大字号。一般长句使用 13px，50–55 字符使用 12px，56–60 字符允许使用 11px，并以保存后截图为准。
- 词汇按英语词项与中文释义成对提取。窄文本框视觉换行不等于语义分行；必须结合配对数量、结构和几何判断，不能唯一分段时停止复核。
- 词汇卡固定为两行四列：每行依次为“英文、中文、英文、中文”；上下两行的四列分别共用同一左边界。列宽按本页上下两行同列的最长内容动态计算，英文参考 `字符数×9+6`，中文参考 `字符数×16+4`，列间距 6px，并将整组在卡片内居中；若超出可用宽度则先按实际渲染测量收敛。每个词项和释义使用独立文本元素与明确坐标，禁止用空格、制表符或会被富文本清洗的内联宽度撑列；旧单文本框不可安全往返时，复制为八个独立文本元素，并用 `editor_replace_element_safe` 两阶段原位设置内容与几何。
- 英文栏目标题按实际字体行高检查字母下缘；出现 `g/p/q/y` 等下降部裁切时，在保持字号与中心线的前提下增高文本框，并给下方说明保留间距。
- 数字模块按源按钮语义和模块类型绑定，禁止依赖“第一个/第二个”或运行时 ID 顺序。
- 顶部“查看＋箭头”的完整外层组必须绑定定位模块，跳转到来源目录中真实承载 Dialogue 内容的区块；禁止只挂在文字或箭头子元素上。
- “查看”定位必须使用 `targetType=block`；回读时 `raw.model_content_resp_en[].catalog_content_en` 必须明确解析出来源书、来源目录和 Dialogue 区块，只有 resourceId 而 catalog_content 为空视为失败。
- 页面末尾必须追加一个手机端 `375×20` 的空区块，零内边距、无元素，纯色背景固定为 `#CECECE`，不得复制设计参考图。
- 当前 Bridge 缺少可执行的页面级画布切换能力时，不调用浏览器改画布。先完成一个已保存回读的 phone 375 成熟基线页，再用 `editor_duplicate_slide` 复制其页面结构；复制后必须确认数字模块未被继承，再逐项绑定当前来源模块。批量 provenance 应在全部页面复制完成后写入，避免把基线页来源追溯复制到其他目录。

## 试制流程

1. 加载 `super-editor-control` 总控和任务需要的最小子技能。
2. 在源书仍连接时导出完整语义快照；`fullFidelity=false` 只能用于预检，写入范围必须避开未可靠读取的内容。
3. 核对来源符合 `applicability`，并选择覆盖常规、结构例外、长内容的代表目录。
4. 创建独立目标界面书，应用样章 41103，按规则顺序写入文本和数字模块。
5. 写前建立 checkpoint；写后保存回读、结构审计、文本适配与全页截图验收。
6. 把来源、样章和目标结果哈希写入运行证据。未完成真实 provenance 后置回读时，只能报告试制结果，不能标为批量验证完成。

## 状态与升级

- 当前规则包为 `validated`；Day 6 的最长句和 Day 19 的两行长标题已完成保存、来源追溯及前向证据回读，可在用户授权的目标书上批量运行。
- 批量时仍须逐页保存回读；遇到超出已验证的标题、句型、词汇数量或模块结构时转为 `needs_review`。
- 新的目录结构、词汇数量不是 4、词义无法唯一分段、模块缺失或同名多义时标记 `needs_review` 并停止当前目录。
- 不自动发布书本；学生端音视频、智能课件、在线答题、智能体和打印点击实测单独报告。
