## 适用边界

在以下条件同时出现时采用本方案：

- 目标是既有成品书中的多个同构目录；
- 需要联动修改富文本、叶子元素几何、背景尺寸和区块高度；
- `editor_text_set_content` 因旧富文本、自定义格式或异常空标签触发安全往返保护；
- 或 `editor_move_element` 对组内叶子仍返回限制，而完整区块导出可用；
- 必须保留“查看”等按钮的 element ID 和已存在数字模块关系。

单个文本或单个顶层元素能被 typed 原子工具安全修改时，继续使用原子工具。不要仅为减少调用次数而替换
区块。不要把本方案用于区块结构差异大、目标映射不唯一、需要重建元素 ID、来源不完整或交互关系无法回读
的页面。

## 安全门禁

调用 `editor_replace_block` 前必须全部满足：

1. 已对当前目录创建 checkpoint；
2. 已用 `editor_export_slide` 导出完整页面，修改对象直接来自该导出结果；
3. replacement 的 `uuid` 等于原 block UUID；
4. 所有需保留元素的 ID、父子层级和未知字段不变；
5. 不用新建后删除文本元素规避校验；该方式可能在保存后恢复旧嵌套元素；
6. 若存在 `template_data_content.ai_semantic_provenance`，完整保留并验证唯一承载区块；
7. 数字模块锚点元素 ID 仍存在，替换后可查询关系；
8. 已在两个结构不同的目录做前向验证；
9. 替换后能截图、审计、`editor_save_verified`，并通过切走再切回的持久化回读。

任一条件不满足时停止，不降级为不保留 ID 的导入、复制或重建。

## 来源冻结与匹配

1. 读取目标书的来源书 ID；缺少直接目录 lineage 时，不虚构 `source_catalog_id`。
2. 在同一任务内用目录名称与顺序做一一匹配，并核对数量、重复名和特殊目录。
3. 在源书连接仍有效时，对全部入选目录执行 `editor_export_semantic_snapshot({richText:"deep"})`。
4. 为每个目录保留源书/目录身份、`snapshotStableHash`、本地 artifact SHA、区块 backend ID、文本
   `plainText/runs/defaultStyle/layout` 和元素几何。
5. 用来源 `runs[].formats.color` 判断强调区间。红色常见为 `#fe2e65` 或 `rgb(254, 46, 101)`，但不要只按
   HTML 标签推断；旧超链接嵌套可能在清洗时生成空标红标签。
6. 单词去除 hyperlink 格式与元数据；只把可见字符和需要保留的语义格式写入目标。
7. 特殊目录先单独分类。基数不等于规则期望值时停止，不用 `slice(0, n)` 静默吞掉多余候选。

运行时 ID 只用于本次证据和替换校验，不进入跨书选择规则。

## 前向验证

先做至少两个目录：

- 一个普通短内容目录；
- 一个长标题、长说明、长单词/音标或长韵律句目录。

每个目录执行：checkpoint → 完整导出 → 内存修改 → 三块原位替换 → 模块回读/创建 → 三块截图 → 审计 →
保存回读 → 切到另一目录 → 切回 → 富文本与模块再次回读。

只有切页回读仍保持以下事实才允许批量：

- block UUID 和目标 element ID 未变化；
- 未标红文字为基础黑色，只有来源 runs 指定字符为红色；
- 单词不再有超链接；
- 数字模块仍挂在原按钮组；
- 页面 `dirty=false` 且内容 hash 等于持久化 hash。

## 单页执行

1. `editor_select_slide({saveBeforeSwitch:true})` 切到目标目录。
2. 创建 checkpoint；导出当前完整页面。
3. 在内存中定位语义区块和叶子元素。组合使用：区块角色、元素类型、名称、可见文本、层级、阅读顺序、
   几何区域和期望基数；不要只靠固定 ID。
4. 直接修改导出对象中的完整区块：保留未知字段、group 结构、block UUID 和 element ID。
5. 对每个受影响区块调用 `editor_replace_block({blockId, templateData})`。不要导入为新区块。
6. 替换完成后再处理数字模块，避免关系创建在即将被替换的元素上。
7. 分别截图受影响区块，执行当前页审计和 `editor_save_verified`。
8. 记录 slideId、source identity、checkpoint、模块动作、截图状态、审计错误/警告、内容 hash 和最终状态。

## 富文本与布局规则

### 基础富文本

- 先生成基础黑色的规范 HTML，再按来源 runs 插入颜色 span；不要继承目标元素可能为红色的默认色。
- 保留目标字号和粗细是默认策略；只有单项实际放不下时才单独缩小。
- 单词和音标设置固定框、`textAlign:center`、`verticalAlign:middle`、零 padding、`extendType:none`，禁止换行。
- 超长项按单项长度缩小并截图验证。不要设全页统一的最小字号；音标明显长于单词时允许更小。
- 中文可设置统一字号，并按规则允许换行；水平和垂直对齐必须同时设置。

### 顶部区块

- 大标题保持单行，优先加宽到操作按钮左侧；不要用换行掩盖宽度不足。
- 说明句限制在白色卡片内宽，设置自动换行和纵向延伸。
- 说明句增加的高度同步下移其后的发音卡片、Logo 和 GO 元素。
- 同步增加白色背景和区块高度；截图确认标题、说明、按钮互不覆盖。

### 主内容区块

- 先用重复背景行或其他稳定视觉锚点计算每行中心，再把单词、音标和中文放到对应行中心。
- 每一列按 top 排序后必须与来源同为期望基数；任何缺失/多余都停止。
- 图片保留目标素材；只替换文字和规定的布局属性。

### 韵律区块

- 英文和中文分别限制最大宽度，设置 `overflowType:["overWithBreak"]` 与纵向延伸。
- 先计算英文实际/保守高度，再放置中文；中文高度变化后重新计算卡其背景底部。
- 背景底部保留固定内边距，再把练习标题、粉色背景和 GO 元素整体移动同一 delta。
- 同步调整白色背景与区块高度。英文或中文右侧超出时，不能只加高背景，必须先让文本在卡片内换行。

## 数字模块

1. 定位可见“查看”按钮的语义组，并记录 element ID。
2. 先调用 `editor_list_digital_modules({includeEmpty:true})`。
3. 已有关联时跳过，不覆盖、不重复创建。
4. 空关联时先 `validateOnly`，再创建定位模块。
5. 定位配置使用当前目标目录 ID，并指向匹配原课件目录的首个有效内容区块 backend ID；不要指向来源
   目录 ID。
6. 创建后回读模块；区块替换后和切页回读后再次确认同一按钮 element ID 仍有关联。

模块创建是立即写库，页面 checkpoint 不能回滚。先验证内容替换方案，再创建模块。

## 批量与恢复

- 批量前冻结全部来源计划，不在循环内重新猜来源。
- 每页独立 checkpoint、替换、模块处理、截图、审计和保存；每 5–10 页输出进度。
- 保持按目录可恢复的账本。状态至少包括 `started/saved/failed/outcome_unknown`。
- 任一工具返回 `OUTCOME_UNKNOWN` 时停止该页，重新读取当前目录、模块和保存状态；不能直接重放。
- 发现新的结构变体时停止批量，先回到前向验证并更新规则。
- 批量完成后按不超过工具上限的 slideId 分组做整书审计，再抽查最长标题、最长说明、最长韵律句、最长
  单词和最长音标目录。

## 验收

必须分别验证：

- 来源匹配数量与特殊目录排除；
- 富文本可见字符、红色 runs、基础色和无超链接；
- 单词/音标单行，中文按规则换行；
- 顶部和韵律区的文本、背景、后续元素与区块高度联动；
- block UUID、element ID、provenance 和模块关系保留；
- 每页截图、审计、保存回读和切页回读；
- 整书审计 error 数量；模板历史警告必须分类，不得当成成功或错误隐去；
- 学生端点击定位未实际执行时明确标为未验证。

## 已验证案例

2026-08-12 在“搞定自然拼读”书类完成一次真实前向与批量验证：

- 来源书与目标书的 124 个普通目录按名称和顺序一一匹配，特殊测试目录排除；
- 从来源 snapshot 的 runs 迁移单词/音标标红，移除单词链接；
- 用完整导出对象原位替换顶部、六行内容和韵律区块，保留 block UUID、element ID 与按钮模块锚点；
- 已有定位模块跳过，缺失模块创建并回读；
- 处理长标题/说明、长韵律句、8–9 字母单词和 12–16 字符音标；
- 124 页保存回读，整书审计 0 error；抽查和切页回读确认内容未恢复旧状态。

案例中的书本 ID、元素 ID、坐标和字号只是运行证据，不得复制成其他书的固定规则。
