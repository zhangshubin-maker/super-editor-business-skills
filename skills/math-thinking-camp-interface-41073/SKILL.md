# 数学思维特训营界面型教辅（41073/41074/41075/41076）

当前规则包是 `0.1.0-draft`。先完整读取 [rule-pack.json](references/rule-pack.json) 和
[routing-and-gaps.md](references/routing-and-gaps.md)；核对具体书目时再读取
[source-inventory.json](references/source-inventory.json)。继续试制前还要读取
[trial-preflight-2026-08-18.json](references/trial-preflight-2026-08-18.json) 和
[runtime-refresh-2026-08-18.json](references/runtime-refresh-2026-08-18.json)，并在新 MCP 任务中完成其中列出的
七个代表页复验。草案未获试制批准，也未完成两个前向案例，禁止批量写书。

## 来源边界

- 完整原课件与四个真实样章是正式依据。`*_analyse.json` 只用于发现历史意图和辅助指纹；文件内出现的
  “打印字帖”“字词听写”“按第几个元素”等旧文案不得直接升级为规则。
- 自动范围只召回当前成套来源：`数学思维特训营`、`数学思维特训营-A版练习+解析`、
  `数学思维特训营-B版练习+解析`。旧 `-全` 与单独 `-A版解析/-B版解析` 只作候选，未经确认不得自动转换。
- 规则以书本语义、目录语义、可见文本、区块邻接、数字模块类型和基数共同匹配；运行时书本、目录、区块、
  元素 ID 只进入来源证据，不作为下一本书的选择器。

## 样章路由

按唯一最高优先级选择：

1. 当前来源是成套全册，且目录名包含“能力达标”时使用 `41075`；目录必须进一步精确区分 A 或 B。
2. A版练习+解析使用 `41074`。
3. B版练习+解析使用 `41076`。
4. 成套全册的其他“学习之旅”目录使用 `41073`。

任何书类不明、A/B 同时命中、能力达标未能精确判断 A/B、或同优先级存在多个合理样章时，标为
`needs_review`，不能回退到默认样章猜测。

## 关键转换规则

- 全册普通目录：把“问题探索”中的一至两道完整题目写入问题卡；不足两道时删除完整的第二题容器。根据
  “解题思路”正文生成简短方法引导语。主查看、名师总结，以及最多两个变式下的思路分析/解答/关键点，
  分别定位到来源中真实承载该语义的区块；没有唯一对应关系时停止当前目录。
- 能力达标：只保留与目录 A/B 相同的 41075 子区块。收集同一单元边界内、当前能力达标之前最近五个
  “学习之旅”知识点，去掉“学习之旅+序号”前缀后按最近到最早填入五个标签。A 使用基础巩固文案，B 使用
  进阶拔高文案。复制一个来源智能体到“AI拍照批改”完整外层组，创建一个指向来源能力达标首个实质内容区块
  的定位模块；来源没有打印模块时删除打印入口，不复制无目标语义的核对答案关系。
- A/B 练习页：从目录名提取知识点，分别生成基础巩固或拔高文案；把两个练习区各自相邻的互动课程关系
  绑定到对应卡片，并创建一个查看定位。
- A/B 解析页：用相同序号的非解析目录唯一配对后取得知识点，生成“A/B版练习题提供思路分析与完整解答”
  文案，只保留解析子区块并创建一个查看定位。

## 执行与验证

1. 加载 `super-editor-semantic-teaching-aid` 与 `super-editor-control`，按任务范围加载最小子技能。
2. 切书前导出 `richText=deep` 的完整语义快照。`fullFidelity=false` 只能做预检；不得据此授权正式写入。
3. 先报告书类、目录分类、解析后的样章、来源/目标角色、基数、缺失与歧义，再等待明确试制或批量授权。
4. 写前建立 checkpoint；目录、数字模块和书本创建属于不可由页面 checkpoint 回退的持久化域。
5. 只用原子能力写入，默认保留样章样式与 375 手机画布。定位必须回读为 `targetType=block`，并能证明
   来源书、来源目录和来源区块；仅有 `resourceId` 不算通过。
6. 每页保存回读、结构审计、文本适配与全页截图。能力达标页必须恰好一个智能体和一个定位模块；A/B练习页
   恰好两个互动课程和一个定位模块；A/B解析页恰好一个定位模块。额外关系属于错误，不沿用历史成品缺陷。
7. provenance 写入后再次保存、导出并用母 Skill 的 `validate-readback` 生成 canonical receipt。学生端点击、
   互动课程与智能体可用性未实测时单独报告。

## 状态升级

- 当前只允许继续分析、修订规则和准备试制，不允许生产批量。
- 用户确认路由与规则后，刷新真实 capability catalog，把规则包升级为 `trial_approved`，再用一个常规目录、
  一个能力达标目录、一个 A/B 练习及其解析做试制。
- 至少两个未参与教授、结构不同的目录完成真实保存、来源追溯与前向证据回读后，才能升级为 `validated`。
- 不自动发布书本。
